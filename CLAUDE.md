## Обзор

Telegram-бот на Go (`github.com/mymmrac/telego` v1). Принимает объявления, присланные ему в личный чат, и публикует их в заданный канал с припиской «by: <автор>». После публикации бот отвечает автору сообщением с inline-кнопкой, которая помечает объявление как неактуальное («Не актуально») или восстанавливает его. Все тексты для пользователей на русском.

## Конфигурация (переменные окружения)

Читаются через типизированные хелперы в `logging.go` (`getEnvOrDefault`, `getEnvIntOrDefault`, `getEnvInt64OrDefault`, `getEnvBoolOrDefault`). Используй их вместо прямого `os.Getenv`: некорректные значения логируются, и подставляется значение по умолчанию.

- `BOT_TOKEN` (обязательно), `CHANNEL_ID` (обязательно, int64 — целевой канал)
- `BOT_AUTH_ENABLED` (по умолчанию `true`) — принимать объявления только от участников канала `CHANNEL_ID`
- `LOG_FILE_PATH` (по умолчанию `logs/telegram-bot.log`), `LOG_MAX_SIZE_MB`, `LOG_MAX_BACKUPS`, `LOG_MAX_AGE_DAYS`, `LOG_COMPRESS` — ротация через lumberjack; логи пишутся и в stdout, и в файл

## Архитектура

Весь код лежит в одном плоском `package main`. Структура `VBBot` (`telegram-bot.go`) хранит клиент бота, ID канала, конфиг и собираемые медиагруппы.

- **Один цикл событий.** `VBBot.Start` делает `select` по каналу обновлений long polling и 5-секундному тикеру. Вся обработка идёт в этой одной горутине, поэтому `mediamsg` — обычная map без блокировок. Сохраняй это, а если добавляешь горутины, добавь и синхронизацию.
- **Обработка сообщения** (`handleUpdate`): групповые чаты (отрицательный chat ID) и `/команды` игнорируются → `authByChannel` (`auth.go`) → `runFilter` (`filter.go`; возвращает `true`, если сообщение нужно *отклонить*) → `sendPlainMessage` / `sendPhotoMessage` / буферизация медиагруппы (`send.go`). Текст или подпись обязательны, пустые сообщения отклоняются.
- **Медиагруппы.** Фото из альбома Telegram присылает отдельными обновлениями с общим `MediaGroupID`. Они собираются в `MediaMessage` (`mediamessage.go`), а тикер переводит его по состояниям `Init → ToBeSent → (отправка) → ToDelete → удаление`. Поэтому альбом публикуется одним `SendMediaGroup` примерно через 10–15 секунд после получения. Подпись ставится только на первый элемент.
- **Callback-кнопки.** Формат callback data: `"<действие>_<chatID канала>_<messageID в канале>"`, где действие — `delete` или `restore`. Обработчики пересобирают пост из `ReplyToMessage` (исходного сообщения автора, на которое ответило подтверждение), редактируют текст или подпись поста в канале (при `delete` — зачёркиванием) и меняют кнопку в сообщении-подтверждении.
- Тексты для пользователей лежат в `phrases.go` (часть пока захардкожена прямо в обработчиках).
